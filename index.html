01 MAIN PRODUCT · 個人開発

旅行費用精算アプリ

旅行中の立て替えをプロジェクトごとに記録し、未精算分だけを対象に「誰が誰にいくら払えば終わるか」を最小限の送金回数で自動計算します。Googleログインと招待URLだけで参加でき、手計算の面倒さとLINEでの端数トラブルをなくすために作りました。

課題
割り勘の手計算と、誰が払ったかの記憶違い
工夫
貪欲法で送金回数を最小化 / 精算済みの支払いを計算から除外
STACK
Next.js · Auth.js · Prisma · PostgreSQL · Tailwind CSS
